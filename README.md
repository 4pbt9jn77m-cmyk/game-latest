# Faktor Sepunya: Lompat & Kutip!

Game platformer Matematik Tingkatan 1 dalam satu fail HTML. Semua kristal nombor mempunyai rupa dan warna yang sama.

## Cara main
- Buka `index.html` dalam pelayar web.
- Gerak dengan butang kiri/kanan atau kekunci anak panah.
- Lompat dengan butang Lompat, Space atau anak panah atas.
- Kutip semua faktor sepunya untuk membuka pintu misi seterusnya.

## Game Over
Apabila nyawa habis, skrin `GAME OVER!` muncul. Butang Mula, Misi Seterusnya, Reset dan kawalan pergerakan dikunci. Pemain mesti menekan `RESTART` di skrin Game Over; permainan bermula semula dari Misi 1, skor 0 dan 3 nyawa.

## Terbitkan melalui GitHub Pages
1. Upload `index.html` ke root repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`, kemudian **Save**.
